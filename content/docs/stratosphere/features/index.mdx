Stratosphere is a Pterodactyl fork, so everything you know from Pterodactyl is still there: the server console,
allocations and ports, startups and egg variables, backups, databases, subusers, SFTP, schedules and the client API.
On top of that it adds a redesigned interface and a set of Minecraft tools that used to need plugins, scripts or a
second panel.

## Setting things up

Some features need a small amount of setup from an administrator:
- [Self-service servers](/docs/stratosphere/features/self-service) and
  [custom domains](/docs/stratosphere/features/domains) read `PTERODACTYL_*` settings from the panel's `.env`.
- [Mods and plugins](/docs/stratosphere/features/mods-and-plugins) need a CurseForge API key before the CurseForge
  tab appears at all. Modrinth works without any key.
- [Auto sleep](/docs/stratosphere/features/auto-sleep) gives back the memory of idle servers, and
  [CPU burst](/docs/stratosphere/features/cpu-burst) is configured per node.
