Stratosphere follows [Semantic Versioning](http://semver.org). Two kinds of builds are published on
[kokofixcomputers/StratPanel](https://github.com/kokofixcomputers/StratPanel/releases):

| Channel | When it is built | What is in it |
| --- | --- | --- |
| **Nightly** | Every push to the `1.0-develop` branch | `panel.tar.gz` (the whole panel, built frontend included) and `panel-ui.tar.gz` (the interface only) |
| **Release** | Every `v*` tag | The same two archives, frozen at that version |

Every archive already contains the built frontend, so there is nothing to compile on your server.

</Callout>

## Published releases

Tagged releases published on GitHub are listed here automatically. Nightly builds are not releases,
so they are left out — see the
[releases page](https://github.com/kokofixcomputers/StratPanel/releases) for those.
